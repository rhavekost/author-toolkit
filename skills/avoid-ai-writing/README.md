# Avoid AI Writing

A single-file writing skill that audits and rewrites content to strip out the patterns that make prose read as AI-generated ("AI-isms"). It detects overused vocabulary, template phrases, filler transitions, significance inflation, rhetorical-question openers, uniform rhythm, and other tells, then either rewrites the text or, in detect-only mode, flags issues by severity (P0/P1/P2) without changing anything. Rule strictness adapts to a context profile (LinkedIn, blog, technical blog, investor email, docs, casual) so the same audit fits short social posts and long-form articles alike.
